About Me

I am a researcher with a PhD in physicochemical sciences, with experience in scientific research, data analysis, Python programming and computational modelling.

My current interests include scientific computing, cloud microphysics modelling, data science and artificial intelligence. I am particularly interested in using computational methods to solve scientific and real-world problems.

Research

My research interests focus on scientific computing, computational modelling and data-driven approaches applied to complex scientific problems.

Scientific Cloud Modelling

Ongoing work using Python-based numerical modelling to investigate cloud microphysics, aerosol activation, supersaturation and warm-rain processes.

Key areas include numerical modelling, sensitivity analysis, model evaluation and comparison of cloud microphysics schemes.

Projects

Python Cloud Microphysics Modelling

Development and analysis of Python-based cloud microphysics simulations, focusing on aerosol activation, supersaturation, droplet growth and warm-rain processes.

The work includes sensitivity experiments, scientific data analysis and comparison with the KiD-A microphysics testbed.
